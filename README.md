Simple TCP Port Scanner
Description

A simple TCP Port Scanner written in C for educational purposes. The program attempts to connect to a range of ports on a target IP address and displays any ports that are open.

This project is useful for learning about:

TCP networking
Sockets programming in C
Port scanning concepts
Basic cybersecurity and network administration
Features
Scan a custom range of TCP ports
Detect open ports
Works on both Linux and Windows
Simple command-line interface
Lightweight and easy to understand
Requirements
Linux
GCC compiler
Standard networking libraries
Windows
MinGW GCC or Visual Studio
Winsock library
